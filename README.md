# IT Expenditure Analysis & Budget Variance Dashboard Using Power BI

## Project Overview

The organization is facing challenges in effectively managing its IT expenditure due to significant variances between actual spending, planned budgets, and forecasted expenditure.

The objective of this project is to analyze IT expenditure, identify budget discrepancies, understand spending patterns, and provide better financial visibility through an interactive Power BI dashboard.

This project uses Microsoft Power BI, Power Query, and DAX to analyze IT expenditure across different months, business areas, countries, IT areas, and cost elements.

## Business Problem

The organization needs better control over its IT financial performance.

The major challenges include:

- Significant differences between actual expenditure and planned budgets.
- Variations between actual and forecasted expenditure.
- Difficulty identifying high-spending business areas.
- Limited visibility into country-wise and IT-area-wise expenditure.
- Lack of detailed cost element analysis.
- Difficulty monitoring monthly expenditure trends.

## Project Objectives

1. Compare Actual Expenditure against Planned Budget.
2. Compare Actual Expenditure against Forecasted Expenditure.
3. Identify monthly spending trends.
4. Analyze expenditure by Business Area and Country.
5. Identify high-cost IT Areas and IT Sub Areas.
6. Analyze expenditure by Cost Element and Cost Element Group.
7. Identify over-budget and under-budget areas.
8. Support better IT budget planning and financial decision-making.
